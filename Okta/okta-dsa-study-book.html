Count elements with an even number of digits

REiteration / math

Problem

Given an array of integers, return how many numbers have an even count of digits.

Example

Input: [12, 345, 2, 6, 7896] → Output: 2. (12 has 2 digits, 7896 has 4 digits — both even.)

Approach — step by step

  1. Loop over each number in the array.
  2. Count digits by repeatedly dividing by 10 (or use log10 for positive numbers).
  3. Special case: 0 has exactly 1 digit (odd) — do not treat it as 0 digits.
  4. If digit count is even, increment your answer counter.

Why this works

Digit counting via division is O(d) per number where d is digits — simple and avoids floating-point issues from log10 on edge values.

Edge cases to mention in interviews

  • Single element arrays.
  • 0 and negative numbers (use abs for digit count).
  • Very large numbers within Int range.
TimeO(n · d)
SpaceO(1)

Swift solution

Swift 
func countEvenDigitNumbers(_ nums: [Int]) -> Int {
    var count = 0
    for n in nums {
        var digits = 0
        var x = abs(n)
        if x == 0 { digits = 1 }
        else { while x > 0 { digits += 1; x /= 10 } }
        if digits % 2 == 0 { count += 1 }
    }
    return count
}

Parse name:value strings — highest average

RMhashmap

Problem

Given strings like "Ram:5", "Shyam:6", "Ram:3", parse name and integer value, then return the name with the highest average value.

Example

Input: ["Ram:5", "Shyam:6", "Ram:3"] → Ram avg = (5+3)/2 = 4, Shyam = 6 → Output: "Shyam".

Approach — step by step

  1. Use a hash map: name → (sum, count).
  2. Split each entry on the first ':' only (names shouldn't contain colons in this problem).
  3. Parse the value as Int; skip malformed lines or handle per spec.
  4. After processing, compute average for each name and pick the maximum.

Why this works

Aggregation in one pass is O(n). Storing sum and count avoids floating-point accumulation errors and makes tie-breaking explicit.

Edge cases to mention in interviews

  • Tie on average — clarify with interviewer (lexicographic, first seen).
  • Malformed entries without colon or non-integer values.
  • Empty input array.
TimeO(n)
SpaceO(k) unique names

Swift solution

Swift 
func highestAverageName(_ entries: [String]) -> String? {
    var totals: [String: (Int, Int)] = [:] // sum, count
    for entry in entries {
        let parts = entry.split(separator: ":", maxSplits: 1)
        guard parts.count == 2, let val = Int(parts[1]) else { continue }
        let name = String(parts[0])
        let (s, c) = totals[name, default: (0, 0)]
        totals[name] = (s + val, c + 1)
    }
    return totals.max { a, b in
        Double(a.value.0) / Double(a.value.1) < Double(b.value.0) / Double(b.value.1)
    }?.key
}

3-Sum — all unique triplets summing to zero

RMsort + two-pointer

Problem

Given an integer array, return all unique triplets [a, b, c] such that a + b + c = 0.

Example

Input: [-1, 0, 1, 2, -1, -4] → Output: [[-1,-1,2], [-1,0,1]] (order of triplets doesn't matter).

Approach — step by step

  1. Sort the array so two-pointer technique applies.
  2. For each index i, run two-pointer on subarray [i+1 .. n-1] looking for pairs that complete sum to 0.
  3. If sum < 0, move left pointer right; if sum > 0, move right pointer left.
  4. On match, record triplet and skip duplicate values at both pointers.
  5. Skip duplicate values at index i as well.

Why this works

Sorting enables O(n²) instead of O(n³) brute force. Duplicate skipping is essential because sorted equal values would otherwise produce repeated triplets.

Edge cases to mention in interviews

  • Fewer than 3 elements → empty result.
  • All zeros → one triplet [0,0,0] if length ≥ 3.
  • No valid triplets → empty array.
TimeO(n²)
SpaceO(1) excluding output

Swift solution

Swift 
func threeSum(_ nums: [Int]) -> [[Int]] {
    let sorted = nums.sorted()
    var result: [[Int]] = []
    for i in 0..<sorted.count {
        if i > 0 && sorted[i] == sorted[i - 1] { continue }
        var l = i + 1, r = sorted.count - 1
        while l < r {
            let sum = sorted[i] + sorted[l] + sorted[r]
            if sum == 0 {
                result.append([sorted[i], sorted[l], sorted[r]])
                l += 1; r -= 1
                while l < r && sorted[l] == sorted[l - 1] { l += 1 }
                while l < r && sorted[r] == sorted[r + 1] { r -= 1 }
            } else if sum < 0 { l += 1 } else { r -= 1 }
        }
    }
    return result
}

Two Sum

PEhashmap

Problem

Given an array of integers and a target, return indices of two distinct elements that sum to target. Exactly one solution exists.

Example

Input: nums = [2, 7, 11, 15], target = 9 → Output: [0, 1] because nums[0] + nums[1] = 9.

Approach — step by step

  1. Maintain a hash map from value → index seen so far.
  2. For each element nums[i], check if (target - nums[i]) is already in the map.
  3. If yes, return [map[complement], i].
  4. Otherwise store nums[i] → i and continue.

Why this works

Each lookup and insert is O(1) amortized, giving one-pass O(n) time versus O(n²) brute force.

Edge cases to mention in interviews

  • Negative numbers and zero as valid values.
  • Same value used twice (e.g. [3,3] target 6) — map stores index before checking complement.
TimeO(n)
SpaceO(n)

Swift solution

Swift 
func twoSum(_ nums: [Int], _ target: Int) -> [Int] {
    var seen: [Int: Int] = [:]
    for (i, n) in nums.enumerated() {
        if let j = seen[target - n] { return [j, i] }
        seen[n] = i
    }
    return []
}

Pairs in sorted array summing to target

PEtwo-pointer

Problem

Given a sorted array and a target, find indices of two elements (one pair) that sum to target.

Example

Input: nums = [1, 2, 4, 6, 10], target = 10 → Output: (2, 4) for values 4 + 6.

Approach — step by step

  1. Place left pointer at start, right pointer at end.
  2. Compute sum = nums[left] + nums[right].
  3. If sum equals target, return indices.
  4. If sum is too small, increment left (need larger value).
  5. If sum is too large, decrement right.

Why this works

Sorted order guarantees that moving left increases sum and moving right decreases it — we never need to revisit discarded pairs.

Edge cases to mention in interviews

  • No pair exists → return nil.
  • Multiple pairs — problem may ask for any one pair.
TimeO(n)
SpaceO(1)

Swift solution

Swift 
func pairSum(_ nums: [Int], _ target: Int) -> (Int, Int)? {
    var l = 0, r = nums.count - 1
    while l < r {
        let sum = nums[l] + nums[r]
        if sum == target { return (l, r) }
        if sum < target { l += 1 } else { r -= 1 }
    }
    return nil
}

Rotate Array in place

PMarrays

Problem

Rotate an array to the right by k steps in O(n) time and O(1) extra space.

Example

Input: [1,2,3,4,5,6,7], k = 3 → Output: [5,6,7,1,2,3,4].

Approach — step by step

  1. Normalize k with k % n (k may be larger than array length).
  2. Reverse the entire array.
  3. Reverse the first k elements.
  4. Reverse the remaining n - k elements.

Why this works

Three reversals relocate the last k elements to the front without extra memory. Example: [1,2,3,4,5] k=2 → reverse all → [5,4,3,2,1] → reverse first 2 → [4,5,3,2,1] → reverse rest → [4,5,1,2,3].

Edge cases to mention in interviews

  • k = 0 or k = n → no change.
  • n = 1.
  • k > n handled by modulo.
TimeO(n)
SpaceO(1)

Swift solution

Swift 
func rotate(_ nums: inout [Int], _ k: Int) {
    let k = k % nums.count
    func rev(_ a: Int, _ b: Int) {
        var i, j = a, b
        while i < j { nums.swapAt(i, j); i += 1; j -= 1 }
    }
    rev(0, nums.count - 1)
    rev(0, k - 1)
    rev(k, nums.count - 1)
}

Majority Element (Boyer–Moore)

PEarrays

Problem

Find the element that appears more than n/2 times. It is guaranteed to exist.

Example

Input: [2, 2, 1, 1, 1, 2, 2] → Output: 2 (appears 4 of 7).

Approach — step by step

  1. Track a candidate and a count.
  2. For each element: if count is 0, set candidate to current element.
  3. If current equals candidate, increment count; else decrement count.
  4. Candidate at end is the majority (no second verification needed when majority guaranteed).

Why this works

Majority element appears more than all others combined, so it cannot be fully 'cancelled' by other elements in the pairing process.

Edge cases to mention in interviews

  • Single element array.
  • All elements identical.
TimeO(n)
SpaceO(1)

Swift solution

Swift 
func majorityElement(_ nums: [Int]) -> Int {
    var candidate = nums[0], count = 1
    for n in nums.dropFirst() {
        if count == 0 { candidate = n; count = 1 }
        else if n == candidate { count += 1 } else { count -= 1 }
    }
    return candidate
}

Top K Frequent Elements

PMhashmap + heap

Problem

Return the k most frequent elements from an integer array. Answer order does not matter.

Example

Input: nums = [1,1,1,2,2,3], k = 2 → Output: [1, 2].

Approach — step by step

  1. Count frequency of each number in a hash map.
  2. Bucket sort: create buckets indexed by frequency (max freq ≤ n).
  3. Place each number in bucket[frequency].
  4. Iterate buckets from highest frequency downward until k elements collected.

Why this works

Bucket sort by frequency runs in O(n) vs O(n log k) for a heap — both are acceptable; buckets are elegant when frequency cap is n.

Edge cases to mention in interviews

  • k equals number of distinct elements.
  • All elements same frequency — any k distinct values work.
TimeO(n)
SpaceO(n)

Swift solution

Swift 
func topKFrequent(_ nums: [Int], _ k: Int) -> [Int] {
    var freq: [Int: Int] = [:]
    for n in nums { freq[n, default: 0] += 1 }
    var buckets = Array(repeating: [Int](), count: nums.count + 1)
    for (n, f) in freq { buckets[f].append(n) }
    var result: [Int] = []
    for i in (0..<buckets.count).reversed() {
        result.append(contentsOf: buckets[i])
        if result.count >= k { return Array(result.prefix(k)) }
    }
    return result
}
Arrays & Hashing

Kth Largest Element

PMheap / quickselect

Problem

Find the kth largest element in an unsorted array (not the kth distinct — kth in sorted order).

Example

Input: [3,2,1,5,6,4], k = 2 → Output: 5 (sorted descending: 6,5,4...).

Approach — step by step

  1. Quickselect: partition array around a pivot like quicksort.
  2. After partition, pivot index p has elements ≥ pivot on left (for kth largest variant).
  3. If p == k-1, done. Else recurse on left or right partition only.

Why this works

Expected O(n) time because we only recurse on one side; worst case O(n²) but rare with random pivot or median-of-medians.

Edge cases to mention in interviews

  • k = 1 → maximum element.
  • Duplicates — partition must treat equals consistently.
TimeO(n) average, O(n²) worst
SpaceO(1)

Swift solution

Swift 
func findKthLargest(_ nums: [Int], _ k: Int) -> Int {
    var arr = nums
    func partition(_ lo: Int, _ hi: Int) -> Int {
        let pivot = arr[hi]
        var i = lo
        for j in lo..<hi {
            if arr[j] >= pivot { arr.swapAt(i, j); i += 1 }
        }
        arr.swapAt(i, hi)
        return i
    }
    var lo = 0, hi = arr.count - 1, target = k - 1
    while true {
        let p = partition(lo, hi)
        if p == target { return arr[p] }
        if p < target { lo = p + 1 } else { hi = p - 1 }
    }
}

Binary-string flip and count simulation

RMsimulation / greedy

Problem

Given a binary string, you may flip any bit (0→1 or 1→0). Simulate or compute: (1) minimum flips to make the string have no consecutive equal bits (alternating pattern), or (2) count operations in a simulation where you flip bits according to a rule until a target state is reached.

Example

Input: "00110" → min flips for alternating: compare pattern starting with 0 ("01010") vs starting with 1 ("10101"); "00110" needs 2 flips to match "01010" and 3 to match "10101" → answer 2.

Approach — step by step

  1. For min-flips alternating: you only have two target patterns — even indices 0 or even indices 1.
  2. Count mismatches against pattern A (start with 0) and pattern B (start with 1) in one pass.
  3. Answer is min(mismatchesA, mismatchesB) — no need to actually flip.
  4. For simulation variants: track current state, apply flip rule per spec, increment counter until done.

Why this works

Alternating binary strings are fully determined by the first bit, so brute force over two patterns is O(n). Simulation problems reduce to greedy: flip when current bit equals previous to enforce alternation.

Edge cases to mention in interviews

  • Empty string → 0 flips.
  • Single character → already alternating.
  • All same bits → n-1 flips for strict alternation of length n.
TimeO(n)
SpaceO(1)

Swift solution

Swift 
func minFlipsToAlternate(_ s: String) -> Int {
    let bits = s.map { $0 == "1" }
    var flip0 = 0, flip1 = 0
    for (i, b) in bits.enumerated() {
        if b != (i % 2 == 0) { flip0 += 1 }
        if b != (i % 2 == 1) { flip1 += 1 }
    }
    return min(flip0, flip1)
}

String OA bundle — palindrome and valid parentheses

REstack / two-pointer

Problem

Common online-assessment string templates: (1) check if a string is a palindrome, (2) check if parentheses/brackets are valid and balanced, (3) longest palindromic substring variant.

Example

Palindrome: "racecar" → true. Valid parentheses: "({[]})" → true, "(]" → false.

Approach — step by step

  1. Palindrome: two pointers from both ends, compare characters (skip non-alphanumeric if required).
  2. Valid parentheses: stack — push opening brackets; on closing, pop and verify match.
  3. If stack empty at end, all pairs matched.
  4. For longest palindrome substring: expand around center for each index (O(n²)) or Manacher's (O(n)).

Why this works

Stack naturally models nested structure — last unmatched opener must pair with current closer. Palindrome two-pointer exploits symmetry without extra memory.

Edge cases to mention in interviews

  • Empty string is palindrome and valid parentheses.
  • Only openers → invalid.
  • Mixed bracket types must match exactly.
TimeO(n) for palindrome/valid parens
SpaceO(n) stack for parentheses

Swift solution

Swift 
func isPalindrome(_ s: String) -> Bool {
    let chars = Array(s.lowercased().filter { $0.isLetter || $0.isNumber })
    var l = 0, r = chars.count - 1
    while l < r {
        if chars[l] != chars[r] { return false }
        l += 1; r -= 1
    }
    return true
}

func isValidParentheses(_ s: String) -> Bool {
    var stack: [Character] = []
    let pairs: [Character: Character] = ["(": "(", "[": "[", "{": "{"]
    let close: [Character: Character] = [")": "(", "]": "[", "}": "{"]
    for ch in s {
        if pairs[ch] != nil { stack.append(ch) }
        else if let open = close[ch] {
            guard let top = stack.popLast(), top == open else { return false }
        }
    }
    return stack.isEmpty
}

File parse and sort

RMparsing

Problem

Read lines from a file (or string array simulating file lines), parse structured fields (CSV, colon-separated, or fixed columns), then sort records by a chosen key and return or write output.

Example

Lines: ["2024-01-01:alice:100", "2024-01-02:bob:50"] sorted by score descending → bob first.

Approach — step by step

  1. Read all lines; trim whitespace and skip empty lines.
  2. Split each line on delimiter; validate field count.
  3. Parse typed fields (dates, integers) into a struct or tuple.
  4. Sort with Swift sort using comparable key; handle stable order if needed.
  5. Map back to output format or write to file.

Why this works

Parse-once, sort-once pipeline is O(n log n) dominated by sort. Using structs makes comparator logic readable and testable.

Edge cases to mention in interviews

  • Malformed lines — skip or error per spec.
  • Empty file.
  • Tie keys — preserve input order if stable sort required.
TimeO(n log n)
SpaceO(n)

Swift solution

Swift 
struct LogRecord: Comparable {
    let date: String
    let name: String
    let score: Int
    static func < (lhs: LogRecord, rhs: LogRecord) -> Bool {
        lhs.score < rhs.score
    }
}

func parseAndSortLines(_ lines: [String]) -> [String] {
    let records: [LogRecord] = lines.compactMap { line in
        let parts = line.split(separator: ":")
        guard parts.count == 3, let score = Int(parts[2]) else { return nil }
        return LogRecord(date: String(parts[0]), name: String(parts[1]), score: score)
    }
    return records.sorted(by: >).map { "\($0.date):\($0.name):\($0.score)" }
}

func abbreviateName(_ name: String) -> String {

}

Okta API 400 error parser

Problem

Parse an Okta-style HTTP 400 error JSON body and extract human-readable error details: errorCode, errorSummary, and per-field errorCauses (field + summary). Return structured result for logging or UI.

Example

JSON: {"errorCode":"E0000001","errorSummary":"Api validation failed","errorCauses":[{"errorSummary":"password","property":"password"}]} → summary + list of field errors.

Approach — step by step

  1. Decode JSON with Codable structs matching Okta error schema.

  3. If decoding fails, return raw string fallback.
  4. Optionally classify errorCode for retry vs user-fixable.

Why this works

Codable gives type-safe parsing; separating summary from field-level causes matches how Okta surfaces validation errors in admin APIs.

Edge cases to mention in interviews

  • Missing errorCauses array.
  • Nested errorCause objects.
  • Non-JSON body on 400.
TimeO(n) JSON size
SpaceO(n)

Swift solution

Swift 
struct OktaErrorCause: Decodable {
    let errorSummary: String?
    let property: String?
}

struct OktaErrorBody: Decodable {
    let errorCode: String?
    let errorSummary: String?
    let errorCauses: [OktaErrorCause]?
}

struct ParsedOktaError {
    let code: String
    let summary: String
    let fieldErrors: [(field: String, message: String)]
}

func parseOkta400(_ json: String) -> ParsedOktaError? {
    guard let data = json.data(using: .utf8),
          let body = try? JSONDecoder().decode(OktaErrorBody.self, from: data) else { return nil }
    let fields = (body.errorCauses ?? []).map {
        (field: $0.property ?? "unknown", message: $0.errorSummary ?? "")
    }
    return ParsedOktaError(
        code: body.errorCode ?? "",
        summary: body.errorSummary ?? "",
        fieldErrors: fields
    )
}

Longest substring without repeating characters

PMsliding window

Problem

Given a string, find the length of the longest substring without repeating characters.

Example

Input: "abcabcbb" → Output: 3 ("abc"). Input: "bbbbb" → 1.

Approach — step by step

  1. Sliding window with left and right pointers.
  2. Hash map stores last seen index of each character.
  3. Expand right; if char seen inside window, move left past previous occurrence.
  4. Track max window size.

Why this works

Each character visited at most twice (enter and leave window) → O(n). Map gives O(1) duplicate detection.

Edge cases to mention in interviews

  • Empty string → 0.
  • All unique → full length.
  • Unicode — clarify if code points or UTF-16 scalars.
TimeO(n)
SpaceO(min(n, alphabet))

Swift solution

Swift 
func lengthOfLongestSubstring(_ s: String) -> Int {
    var last: [Character: Int] = [:]
    var left = 0, best = 0
    for (right, ch) in s.enumerated() {
        if let prev = last[ch], prev >= left { left = prev + 1 }
        last[ch] = right
        best = max(best, right - left + 1)
    }
    return best
}

String permutations

PMbacktracking

Problem

Return all permutations of a string (or next permutation). For unique permutations when duplicates exist, skip duplicate branches.

Example

Input: "abc" → ["abc","acb","bac","bca","cab","cba"].

Approach — step by step

  1. Backtrack: swap current index with each position from i to end, recurse, swap back.
  2. For unique permutations: sort string first; when swapping, skip if same char as previous swap at this level.
  3. Collect when index reaches end.

Why this works

Backtracking explores all arrangements; duplicate skipping after sort is standard LeetCode unique permutations trick.

Edge cases to mention in interviews

  • Single character → one permutation.
  • All same chars → one permutation.
  • Empty → empty list.
TimeO(n · n!)
SpaceO(n) recursion

Swift solution

Swift 
func permute(_ s: String) -> [String] {
    var chars = Array(s), result: [String] = []
    func backtrack(_ start: Int) {
        if start == chars.count { result.append(String(chars)); return }
        var used = Set<Character>()
        for i in start..<chars.count {
            if used.contains(chars[i]) { continue }
            used.insert(chars[i])
            chars.swapAt(start, i)
            backtrack(start + 1)
            chars.swapAt(start, i)
        }
    }
    backtrack(0)
    return result
}

Minimum in rotated sorted array

RMbinary search

Problem

A sorted array was rotated at some pivot. Find the minimum element. No duplicates (or handle duplicates separately).

Example

Input: [4,5,6,7,0,1,2] → Output: 0. Input: [3,4,5,1,2] → 1.

Approach — step by step

  1. Binary search on index range with lo, hi.
  2. Compare mid with hi: if nums[mid] > nums[hi], min is in right half (lo = mid+1).
  3. Else min is at mid or left (hi = mid).
  4. When lo == hi, that's the minimum index.

Why this works

Rotated sorted array has one valley; comparing mid to hi tells which side still contains the rotation breakpoint without scanning.

Edge cases to mention in interviews

  • Not rotated (already sorted) → first element.
  • Single element.
  • Two elements.
TimeO(log n)
SpaceO(1)

Swift solution

Swift 
func findMinRotated(_ nums: [Int]) -> Int {
    var lo = 0, hi = nums.count - 1
    while lo < hi {
        let mid = lo + (hi - lo) / 2
        if nums[mid] > nums[hi] { lo = mid + 1 } else { hi = mid }
    }
    return nums[lo]
}
Binary Search

Sqrt(x)

PEbinary search

Problem

Compute integer square root of non-negative x (floor of sqrt).

Example

Input: 8 → Output: 2 (2²=4, 3²=9). Input: 0 → 0.

Approach — step by step

  1. Binary search on answer in [0, x] (or [0, x/2+1] for x>1).
  2. If mid*mid <= x, record mid and try larger (lo = mid+1).
  3. Else too big (hi = mid-1).
  4. Return last valid mid.

Why this works

Monotonic predicate — if k² ≤ x, all smaller k also work; binary search finds maximum k.

Edge cases to mention in interviews

  • x = 0 or 1.
  • Perfect squares.
  • Very large x — use multiplication carefully or bit length bound.
TimeO(log x)
SpaceO(1)

Swift solution

Swift 
func mySqrt(_ x: Int) -> Int {
    if x < 2 { return x }
    var lo = 1, hi = x / 2, ans = 0
    while lo <= hi {
        let mid = lo + (hi - lo) / 2
        let sq = mid * mid
        if sq <= x { ans = mid; lo = mid + 1 } else { hi = mid - 1 }
    }
    return ans
}

Search in rotated sorted array

PMbinary search

Problem

Search target in rotated sorted array with distinct values. Return index or -1.

Example

Input: nums = [4,5,6,7,0,1,2], target = 0 → Output: 4.

Approach — step by step

  1. Binary search: identify which half [lo,mid] or [mid,hi] is sorted.
  2. If target falls in sorted half's range, search there; else other half.
  3. Standard O(log n) without pivot precomputation.

  • Repeated letters requiring careful unmark.

SpaceO(L) recursion

func exist(_ board: [[Character]], _ word: String) -> Bool {
    guard !word.isEmpty else { return true }
    let rows = board.count, cols = board[0].count
    var grid = board
    let chars = Array(word)

    func dfs(_ r: Int, _ c: Int, _ idx: Int) -> Bool {
        if idx == chars.count { return true }
        if r < 0 || c < 0 || r >= rows || c >= cols || grid[r][c] != chars[idx] { return false }
        let ch = grid[r][c]
        grid[r][c] = "#"
        let found = dfs(r+1,c,idx+1) || dfs(r-1,c,idx+1) || dfs(r,c+1,idx+1) || dfs(r,c-1,idx+1)
        grid[r][c] = ch
        return found
    }

    for r in 0..<rows {
        for c in 0..<cols where board[r][c] == chars[0] {
            if dfs(r, c, 0) { return true }
        }
    }
    return false
}

Problem

In a binary or integer matrix, find the maximum sum of any rectangle (or max area of 1s). Avoid O(n²m²) brute force over all corner pairs.

Example

  1. Treat each row as base of histogram: heights[i] = consecutive 1s stacked from above.
  2. For each row, run 'largest rectangle in histogram' on heights array.
  3. Histogram: for each bar, expand left/right while bars taller using monotonic stack.
  4. Track global max area/sum across all rows.

Reduces 2D rectangle search to O(n·m) per row histogram solve — total O(n·m²) or O(n·m) with optimized histogram, far better than enumerating all rectangles.

  • All zeros → 0.
  • Single row/column.
  • Full matrix ones.
TimeO(n · m²) typical
SpaceO(m)

func maximalRectangle(_ matrix: [[Int]]) -> Int {
    guard !matrix.isEmpty else { return 0 }
    let cols = matrix[0].count
    var heights = Array(repeating: 0, count: cols)
    var best = 0

    func largestInHistogram(_ h: [Int]) -> Int {
        var stack: [Int] = [], maxArea = 0
        for i in 0...h.count {
            let cur = i == h.count ? 0 : h[i]
            while let top = stack.last, h[top] > cur {
                stack.removeLast()
                let height = h[top]
                let width = stack.isEmpty ? i : i - stack.last! - 1
                maxArea = max(maxArea, height * width)
            }
            stack.append(i)
        }
        return maxArea
    }

    for row in matrix {
        for c in 0..<cols {
            heights[c] = row[c] == 1 ? heights[c] + 1 : 0
        }
        best = max(best, largestInHistogram(heights))
    }
    return best
}

func rotateMatrix90(_ matrix: inout [[Int]]) {

func isBalanced(_ root: TreeNode?) -> Bool {

func shortestPathBFS(_ graph: [Int: [Int]], from start: Int, to target: Int) -> Int {
    if start == target { return 0 }

struct UnionFind {
    private var parent: [Int]
    private var count: Int

    init(_ n: Int) {
        parent = Array(0..<n)
        count = n
    }

    mutating func find(_ x: Int) -> Int {
        if parent[x] != x { parent[x] = find(parent[x]) }
        return parent[x]
    }

    mutating func union(_ a: Int, _ b: Int) {
        let ra = find(a), rb = find(b)
        if ra == rb { return }
        parent[ra] = rb
        count -= 1
    }

    var components: Int { count }
}

func canPartition(_ nums: [Int]) -> Bool {
    let total = nums.reduce(0, +)

    dp[0] = true

        for s in (num...target).reversed() {
            dp[s] = dp[s] || dp[s - num]

    }

  1. DP O(n²): dp[i] = 1 + max dp[j] for j<i if nums[j]<nums[i].
  2. Patience sorting O(n log n): tails[i] = smallest tail of increasing subseq length i+1.
  3. Binary search position of nums[i] in tails.

Why this works

tails array is always sorted; replacing tail keeps same length but better extension potential — classic LIS optimization.

Edge cases to mention in interviews

  • Strictly decreasing → 1.
  • All equal → 1 if strict increasing required.
  • Empty → 0.
TimeO(n log n)
SpaceO(n)

func lengthOfLIS(_ nums: [Int]) -> Int {
    var tails: [Int] = []
    for n in nums {
        var lo = 0, hi = tails.count
        while lo < hi {
            let mid = lo + (hi - lo) / 2
            if tails[mid] < n { lo = mid + 1 } else { hi = mid }
        }
        if lo == tails.count { tails.append(n) } else { tails[lo] = n }
    }
    return tails.count
}

Longest common subsequence

PMDP

Problem

Given strings text1 and text2, return length of longest common subsequence.

Example

text1="abcde", text2="ace" → 3 ("ace").

Approach — step by step

  1. 2D DP: dp[i][j] = LCS of text1[0..i] and text2[0..j].
  2. If chars match: dp[i][j] = dp[i-1][j-1] + 1.
  3. Else: max(dp[i-1][j], dp[i][j-1]).
  4. Can compress to 1D row for space O(min(n,m)).

Why this works

LCS builds from prefixes — mismatch takes best without one char. Foundation for diff/edit distance variants.

Edge cases to mention in interviews

  • Empty string → 0.
  • Identical strings → length.
  • No common char → 0.
TimeO(n · m)
SpaceO(n · m) or O(min(n,m))

Swift solution

Swift 
func longestCommonSubsequence(_ a: String, _ b: String) -> Int {
    let a = Array(a), b = Array(b)
    var dp = Array(repeating: Array(repeating: 0, count: b.count + 1), count: a.count + 1)
    for i in 1...a.count {
        for j in 1...b.count {
            if a[i-1] == b[j-1] { dp[i][j] = dp[i-1][j-1] + 1 }
            else { dp[i][j] = max(dp[i-1][j], dp[i][j-1]) }
        }
    }
    return dp[a.count][b.count]
}

0/1 Knapsack

PMDP

Problem

Given weights and values of items and capacity W, maximize total value picking each item at most once.

Example

weights=[1,2,3], values=[6,10,12], W=5 → 22 (items 2 and 3).

Approach — step by step

  1. dp[w] = max value with capacity w.
  2. For each item (wt, val), iterate w from W down to wt.
  3. dp[w] = max(dp[w], dp[w-wt] + val).
  4. Backward iteration preserves 0/1 constraint.

Why this works

Forward iteration would allow reusing same item; backward update ensures each item counted once per row.

Edge cases to mention in interviews

  • Capacity 0 → 0.
  • Item heavier than W → skip.
  • All items fit → sum all values.
TimeO(n · W)
SpaceO(W)

Swift solution

Swift 
func knapsack01(weights: [Int], values: [Int], capacity: Int) -> Int {
    var dp = Array(repeating: 0, count: capacity + 1)
    for i in 0..<weights.count {
        let w = weights[i], v = values[i]
        for c in (w...capacity).reversed() {
            dp[c] = max(dp[c], dp[c - w] + v)
        }
    }
    return dp[capacity]
}

LRU Cache (thread-safe with NSLock)

PMdesign

Problem

Design LRU cache with get and put in O(1), capacity limit, evict least recently used on overflow. Thread-safe variant uses NSLock for concurrent access.

Example

capacity=2: put(1,1), put(2,2), get(1)→1, put(3,3) evicts key 2, get(2)→-1.

Approach — step by step

  1. Hash map key → node in doubly linked list.
  2. List order: head = most recent, tail = LRU.
  3. get: move node to head. put: update or insert at head; evict tail if over capacity.
  4. NSLock around get/put for thread safety on shared cache.

Why this works

Hash map gives O(1) lookup; doubly linked list O(1) reorder and eviction. Lock granularity should be per-cache not global.

Edge cases to mention in interviews

  • Capacity 0 — define behavior.
  • Update existing key refreshes recency.
  • Concurrent get/put — lock prevents torn reads.
TimeO(1) get/put
SpaceO(capacity)

Swift solution

Swift 
final class LRUCache {
    private class Node {
        let key: Int
        var value: Int
        var prev: Node?
        var next: Node?
        init(_ key: Int, _ value: Int) { self.key = key; self.value = value }
    }

    private let capacity: Int
    private var map: [Int: Node] = [:]
    private let head = Node(0, 0), tail = Node(0, 0)
    private let lock = NSLock()

    init(_ capacity: Int) {
        self.capacity = capacity
        head.next = tail; tail.prev = head
    }

    private func moveToHead(_ node: Node) {
        remove(node); insertAfterHead(node)
    }

    private func remove(_ node: Node) {
        node.prev?.next = node.next
        node.next?.prev = node.prev
    }

    private func insertAfterHead(_ node: Node) {
        node.prev = head; node.next = head.next
        head.next?.prev = node; head.next = node
    }

    private func popTail() -> Node? {
        guard let node = tail.prev, node !== head else { return nil }
        remove(node); return node
    }

    func get(_ key: Int) -> Int {
        lock.lock(); defer { lock.unlock() }
        guard let node = map[key] else { return -1 }
        moveToHead(node)
        return node.value
    }

    func put(_ key: Int, _ value: Int) {
        lock.lock(); defer { lock.unlock() }
        if let node = map[key] {
            node.value = value; moveToHead(node)
        } else {
            let node = Node(key, value)
            map[key] = node; insertAfterHead(node)
            if map.count > capacity {
                if let lru = popTail() { map.removeValue(forKey: lru.key) }
            }
        }
    }
}

Hit counter (past 5 minutes)

PMdesign

Problem

Design hit counter counting hits in past 5 minutes (300 seconds). hit(timestamp) records hit; getHits(timestamp) returns count in [timestamp-299, timestamp].

Example

hit(1), hit(2), hit(3), getHits(4)→3, hit(300), getHits(300)→4, getHits(301)→3.

Approach — step by step

  1. Queue of timestamps or circular buffer of 300 buckets (second mod 300).
  2. Ring buffer: counts[tsec % 300] += 1 on hit; track total and subtract expired bucket when time advances.
  3. getHits clears buckets older than 300 seconds from current.

Why this works

Ring buffer gives O(1) hit and amortized O(1) getHits without storing every hit — scalable for high QPS.

Edge cases to mention in interviews

  • Non-monotonic timestamps — clarify spec.
  • Multiple hits same second — bucket counts frequency.
  • getHits before any hit → 0.
TimeO(1) hit, O(300) worst getHits with ring cleanup
SpaceO(300)

Swift solution

Swift 
final class HitCounter {
    private var buckets = Array(repeating: 0, count: 300)
    private var times = Array(repeating: 0, count: 300)
    private var total = 0

    func hit(_ timestamp: Int) {
        let idx = timestamp % 300
        if times[idx] != timestamp {
            times[idx] = timestamp
            total -= buckets[idx]
            buckets[idx] = 1
        } else {
            buckets[idx] += 1
        }
        total += 1
    }

    func getHits(_ timestamp: Int) -> Int {
        var count = total
        for i in 0..<300 {
            if timestamp - times[i] >= 300 { count -= buckets[i] }
        }
        return count
    }
}

  3. Parse each octet: no empty, no leading zeros issue per spec, value 0-255.
  4. If port present, parse int 1-65535.

Why this works

Edge cases to mention in interviews

  • Missing octet.
  • Leading/trailing spaces.
  • Port only without host.

SpaceO(1)

func isValidIPv4WithPort(_ s: String) -> Bool {
    let trimmed = s.trimmingCharacters(in: .whitespaces)
    var host = trimmed
    var portPart: String?
    if let colon = trimmed.lastIndex(of: ":") {
        host = String(trimmed[..<colon])
        portPart = String(trimmed[trimmed.index(after: colon)...])
    }
    let octets = host.split(separator: ".", omittingEmptySubsequences: false)
    guard octets.count == 4 else { return false }
    for part in octets {
        guard !part.isEmpty, let n = Int(part), n >= 0 && n <= 255 else { return false }
        if part.count > 1 && part.first == "0" { return false }
    }
    if let portPart {
        guard let p = Int(portPart), p >= 1 && p <= 65535 else { return false }
    }
    return true
}
