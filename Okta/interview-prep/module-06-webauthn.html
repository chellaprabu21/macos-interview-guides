Concept Summary

WebAuthn (FIDO2) replaces passwords with public-key cryptography bound to authenticators (security keys, platform authenticators like Touch ID, passkeys). The Relying Party (JumpCloud auth) issues challenges; authenticators sign with private keys that never leave hardware. Okta FastPass leverages the same phishing-resistant properties in OIE policies.

JumpCloud configures go-webauthn/webauthn with UV discouraged for broader compatibility and PreferNoAttestation to reduce privacy/metadata overhead while retaining phishing resistance via origin binding.

Okta Parallel

Okta FastPass is configured as a phishing-resistant, hardware-protected possession factor in OIE. Auth policies can require "Phishing resistant" + "Hardware protected" for sensitive apps. JumpCloud WebAuthn RP implements the server side of the same W3C ceremony; FastPass adds Okta Verify as the client authenticator with device registration in Universal Directory.

macOS Connection

Platform SSO and Safari SSO extension (jcagent-tray-ssoe) use Apple's native authentication path. Touch ID integrates with platform authenticators - same hardware Okta leverages for Desktop Password Sync enrollment requiring Touch ID before FastPass setup on existing macOS accounts.

Interview Q&A

Why PreferNoAttestation?
Attestation reveals authenticator model/manufacturer - useful for enterprise policy but adds privacy and complexity. JumpCloud prioritizes phishing resistance (origin + challenge binding) over hardware provenance attestation. Okta similarly focuses on factor properties in policy rather than attestation metadata for most deployments.
What is sign counter clone detection?
Authenticator increments signature counter each auth. RP stores last value; if new counter ≤ stored, possible cloned credential - reject auth. Critical FIDO2 security property to mention in security-focused interviews.
ADR-008 push MFA - why WebAuthn-shaped?
Mobile push devices aren't browsers but benefit from challenge-response signing semantics. Reusing WebAuthn protocol shape (QR enrollment, signed challenges) gives consistent security model across platform keys, security keys, and push - reduces one-off crypto protocols.
Hybrid Postgres + Mongo storage?
ADR-004: credential public keys and metadata in Postgres (auth's source of truth); Mongo holds pointer/reference for legacy integration. Tradeoff from incremental migration - know the why, not just the what.

Gaps & Honest Limits

  • WebAuthn RP is server-side in jumpcloud-auth - macOS client integration for FastPass-like silent auth is JumpCloud Go/DURT, not WebAuthn directly.
  • Passkeys/synced credentials policy differs from device-bound keys - know when Okta requires hardware-protected vs allows synced passkeys.
